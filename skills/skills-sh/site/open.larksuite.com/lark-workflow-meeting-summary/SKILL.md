</span><span class="code-line"><span class="token comment"># 批量获取纪要文档与逐字稿链接: 一次最多查询 10 个文档</span>

<h3>Step 4: 整理纪要报告</h3>
<p>根据时间跨度选择输出格式：</p>
<ul>
<li><strong>单日汇总</strong>（"今天"/"昨天"）：用"今日会议概览"标题，逐会议列出会议时间、主题、纪要链接、逐字稿链接（<code>unified</code> 纪要无逐字稿链接，标注"unified 纪要，逐字稿需 <code>note +transcript</code> 拉取"）。</li>
<li><strong>多日/周报</strong>（"这周"/"过去 7 天"等）：用"会议纪要周报"标题，含概览统计、逐会议详情。</li>
</ul>
<h3>Step 5: 生成文档（可选，用户要求时）</h3>
<p>阅读 <a href="https://open.larksuite.com/lark-cli/skills/regular/.well-known/agent-skills/../lark-doc/SKILL.md" target="_blank" rel="ugc nofollow noopener"><code>../lark-doc/SKILL.md</code></a> 学习云文档技能。</p>
<pre class="language-bash"><code class="language-bash code-highlight"><span class="code-line">lark-cli docs +create --doc-format markdown <span class="token parameter variable">--content</span> <span class="token string">$'&#x3C;title>会议纪要汇总 (&#x3C;start> - &#x3C;end>)&#x3C;/title><span class="token entity" title="\n">\n</span>&#x3C;内容>'</span>
</span><span class="code-line"><span class="token comment"># 或追加到已有文档</span>
</span><span class="code-line">lark-cli docs +update <span class="token parameter variable">--doc</span> <span class="token string">"&#x3C;url_or_token>"</span> <span class="token parameter variable">--command</span> append --doc-format markdown <span class="token parameter variable">--content</span> <span class="token string">$'&#x3C;内容>'</span>
