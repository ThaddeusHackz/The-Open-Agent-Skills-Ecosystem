# Deepline Scoring

## Quick Start

```
npm install -g deepline
deepline -h
```

Find evidence for the customer's decision. Use approved rules or a separately evaluated model for scoring. Phrase matches and prevalence ratios alone cannot supply scoring weights.

For account-fit and propensity work, always collect relevant website language, materialize account-level phrase/concept features, and show their model role and score contributions. Industry, size and geography alone are a baseline. If website evidence or approved scoring mappings are missing, disclose the gap rather than silently substituting that baseline. Follow [website account features](https://code.deepline.com/.well-known/skills/archives/references/account-website-features.md); preserve an approved incumbent when auditing or replaying it.
