# 爆款结构拆解器 (Content-Judge)

## Skill 目标

不是学写作，而是学「判断什么值得写」。

大多数人刷到爆款内容，第一反应是："写得真好。"而系统型创作者的第一反应是："它为什么会被传播？"

这个 Skill 的作用，是把模糊的"感觉"，训练成稳定可复用的判断力。

## 什么时候用？

- 你刷到一篇高赞公众号文章
- 一条转发很多的小红书内容
- 一个点赞明显异常的视频文案
- 想分析为什么某篇内容会火

**⚠️ 不要改写，先拆解。**

## 操作步骤

1. 只选择已经被验证的数据内容（高赞/高转发）
2. 不看"写得好不好"，只看"结构怎么走"
3. 强迫自己用结构化语言说清楚：它是怎么吸引人的

## Skill 执行 Prompt

SYSTEM：你是一个内容结构分析 Skill。你的职责是"判断内容结构是否值得复用"，而不是优化内容。

TASK：分析输入内容，并给出结构化判断。

RULES：
- 不改写、不润色原内容
- 不主观夸赞
- 信息不足请标注「未知」
- 判断基于结构与传播机制，而非个人喜好

OUTPUT（严格按以下结构）：

1）核心观点（一句话）

2）目标读者与使用场景

3）内容展开路径（编号列表）

4）注意力钩子（类型 + 原句）

5）情绪变化曲线（开头 / 中段 / 结尾）

6）论证方式（如：故事 / 对比 / 权威 / 反直觉）

7）可复用表达结构（3–5 个模板）

8）复用判断（是否值得复用 + 原因）

## 成熟标志

✅ 你可以把任意内容丢进这个 Skill，得到一个明确可执行的"是否复用"判断。

这是整个内容永动机的起点技能。
