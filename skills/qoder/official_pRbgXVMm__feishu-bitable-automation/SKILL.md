## 🚀 快速开始

### 1. 理解核心概念
自动化 = 触发条件 + 执行操作

**示例**：
```
当【添加记录时】→ 执行【发送消息】给负责人
```

### 2. 创建第一个自动化
1. 打开多维表格 → 点击右上角「自动化」
2. 点击「+ 创建自动化流程」
3. 选择触发条件（如：定时触发）
4. 添加执行操作（如：发送消息）
5. 保存并启用

### 3. 参考实战场景
查看 `guides/02-common-workflows.md`，复制场景配置到你的表格。

## 📊 触发条件一览（7种）

| 触发条件 | 适用场景 | 特点 |
|----------|----------|------|
| 添加记录时 | 表单收集后自动处理 | 实时，常用于通知、分配 |
| 修改记录时 | 状态变更时触发 | 监控关键字段变化 |
| 满足条件时 | 新增或修改满足规则 | 灵活，支持多条件 |
| 到达时间时 | 截止日期提醒 | 基于日期字段，准点触发 |
| 定时触发 | 每日/每周汇总 | 固定时间，不依赖记录 |
| 点击按钮时 | 手动触发复杂流程 | 完全人工控制 |
| 接收 Webhook | 外部系统集成 | 跨系统自动化 |

## 💡 实战场景示例

### 场景：任务逾期自动提醒
```
触发：定时（每天 09:00）
→ 查找：截止日期=今天 且 状态≠已完成
→ 循环每条任务：
   → 发送消息给负责人："⚠️ 任务【{{任务名}}】今天截止！"
   → 通知项目经理（汇总）
→ 设置任务状态=逾期
```

### 场景：库存不足预警
```
触发：修改记录（关注「库存数量」）
条件：库存数量 ≤ 安全库存
→ 发送消息给采购负责人
→ 标记「需要补货」= 是
```

### 场景：日报自动生成
```
触发：定时（每天 17:00）
→ 查找今天完成任务
→ 循环构建日报内容
→ 发送消息到项目群
```

## 🎨 高级功能

### Webhook 触发（外部系统）
- 接收外部 HTTP POST 请求
- 自动创建/更新记录
- 场景：网站表单 → 客户线索自动录入

### HTTP 请求（调用外部）
- 向任意 URL 发送请求
- 调用第三方 API（如 AI、CRM）
- 支持 GET/POST/PUT/DELETE

### 消息卡片
- 结构化、美观的消息
- 支持图片、按钮、多列布局
- 适合发送周报、战报、汇总

### AI 集成
- **AI 分类**：自动给文本打标签
- **AI 生成**：摘要、翻译、扩写
- 调用 StepFun/OpenAI API

## ⚠️ 合规与风险

### 允许的自动化
- ✅ 数据同步、汇总、通知
- ✅ 自动分配、状态流转
- ✅ 定时报告、预警
- ✅ 外部系统集成（合规场景）

### 禁止的自动化
- ❌ 自动点赞/评论/关注（违反平台规则）
- ❌ 批量注册、群控操作
- ❌ 绕过验证、刷数据
- ❌ 高频请求（触发风控）

**原则**：自动化是提效工具，不是作弊手段。遵守平台规则，合理控制频率。

## 🆘 学习路径

**新手**（1-2小时）：
1. 阅读 `01-triggers-actions.md` 前 3 节
2. 配置 2-3 个简单自动化（发送消息、创建记录）
3. 查看运行日志，理解执行流程

**进阶**（半天）：
1. 学习「查找记录」+「循环」批量处理
2. 配置「定时汇总」场景
3. 使用条件判断实现复杂逻辑

**高级**（1周+）：
1. Webhook 触发 + HTTP 请求
2. 消息卡片设计
3. AI 能力集成
4. 性能优化与错误处理
