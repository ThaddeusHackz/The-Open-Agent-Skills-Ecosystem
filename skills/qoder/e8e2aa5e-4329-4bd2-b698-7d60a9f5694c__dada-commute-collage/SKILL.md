# 达达主义都市通勤拼贴

## When to use
- 用户要「达达主义 / 拼贴 / 通勤 / 手绘拼贴」风格的生图
- 关键词触发：达达主义拼贴、都市通勤拼贴、通勤物料混合媒体、日常碎片美学、手绘拼贴生图、commute collage、dada collage、达达人脸、拼贴脸
- 所有生图统一走平台的图像生成能力（文本生图 / 图生图）

## 风格定义（写进 prompt 的核心要素）
物料清单（务必点名，越具体越准）：
- 地铁票根 subway ticket stubs
- 打车小票 taxi / ride-hailing receipts
- 咖啡杯套 coffee cup sleeves
- 便利店收据 convenience-store receipts
- 地铁广告剪片 subway ad clippings
- 通勤路线手绘草图 hand-drawn commute-route sketches
- 圆珠笔涂鸦线条 ballpoint-pen doodle lines
- 便利贴撕片 torn sticky-note scraps
- 布标边角料 fabric-label scraps

构图与气质：
- 错叠分层、秩序打乱重排、随机拼贴、超现实达达主义
- 多种不同质感印刷纸品（哑光 / 铜版纸 / 热敏纸 / 瓦楞纸）
- 纸张撕裂边缘 + 胶带粘贴痕迹
- 配色：城市灰蓝底 + 票据米白 + 荧光黄粉便利贴点缀

## Steps
1. 确认构图方向（三选一，默认横版拼贴墙）：
   - A 竖版手账（1024x1536）：像一页摊开的通勤手账拼贴画
   - B 横版拼贴墙（1536x1024）：铺陈展开、细节密集
   - C 方版人脸（1024x1024）：先写实人脸，再达达化改造
2. 调用图像生成能力生图（prompt 见下方模板，quality=high）。
3. 若做达达人脸（C）：先出写实人脸（quality=high, 1024x1024），再用该图做图生图（image-to-image），风格相似度设低（约 0.4），prompt 走「达达主义拼贴脸」模板。
4. 展示生成结果图。

## Prompt 模板
通勤拼贴（横版 B）：
「手绘+拼贴风格艺术品，以当代都市日常通勤为灵感。包含：地铁票根、打车小票、咖啡杯套、便利店收据、地铁广告剪片、通勤路线手绘草图、圆珠笔涂鸦线条、便利贴撕片、布标边角料。横版铺陈构图，错叠分层的多种不同质感印刷纸品，秩序打乱重排，日常碎片美学，随机拼贴，通勤物料混合媒体，超现实达达主义。纸张有撕裂边缘与胶带粘贴痕迹，城市灰蓝底色，票据米白与荧光黄粉便利贴点缀，像一面展开的达达主义通勤拼贴墙，细节密集、质感真实、层次丰富」

通勤拼贴（竖版 A）：同上，把「横版铺陈构图……像一面展开的拼贴墙」改为「竖版构图，像一本摊开的通勤手账拼贴画」。

达达人脸（C 改造）：图生图传入写实人脸图，风格相似度设 0.4，prompt：
「达达主义风格的人脸拼贴艺术。把写实人脸撕裂、错位重组：双眼高低不一、嘴与鼻错位拼接，脸庞由撕碎的票据、报纸剪片、圆珠笔涂鸦、胶带粘贴痕迹拼合而成，混入地铁票根与便利贴碎片，超现实荒诞构图，多种纸质拼贴层叠，粗糙手工感与印刷质感并存，灰蓝与米白底色加荧光黄粉点缀」

## 变体菜单（prompt 微调）
- 方形 1:1 封面感 / 局部特写（只放大票根+路线图一块）
- 色调重做：暖做旧（牛皮纸+褪色油墨）或冷霓虹（夜班通勤感）
- 与通勤拼贴合流：把达达脸塞进横/竖版拼贴当视觉主角
- 加更多破坏：五官再错位、文字涂鸦、眼鼻互换

## Pitfalls
- 不要依赖图像生成接口的 `style` 字段控制风格，靠 prompt 描述最稳。
- 人脸达达化必须走图生图（input 传原图），直接文生图容易丢失可辨识人脸。
- 切换对话主模型不影响生图效果（生图走独立生图后端）；效果差异来自 prompt / size / quality / 风格相似度参数。
- 每次生图消耗额外额度（约 5–10/张），调用前提示用户。

## Verification
- 检查生成图是否同时出现 3 类以上物料（票据 / 手绘 / 便利贴）且呈错叠分层而非平铺。
- 达达人脸应保留可辨识人脸轮廓但五官错位、带撕裂拼贴痕迹。
- 若物料缺失或太规整，提高 prompt 中「随机拼贴 / 秩序打乱重排 / 撕裂边缘」的权重再生成。
