# AI工具社媒种草文生成器

## 功能概述

帮助用户将AI工具的使用体验快速转化为适合社交媒体传播的种草帖/测评文。支持小红书和微博两种平台风格输出，自动适配各平台的内容调性和格式规范。

## 适用场景

- AI博主想快速产出工具测评内容
- 科技自媒体需要批量产出AI工具推荐帖
- 产品运营需要为自家AI产品撰写社媒传播素材
- 任何人体验了一个好用的AI工具想分享给别人

## 使用步骤

### Step 1：收集用户输入

向用户询问以下信息（必填项标*）：

1. *工具名称：要推荐的AI工具是什么？
2. *核心功能：这个工具主要做什么？（一句话描述）
3. *使用场景：你用它解决了什么问题？
4. 惊喜点：使用过程中最让你惊喜的地方是什么？
5. 槽点/不足：有什么不够好的地方吗？（真实感关键）
6. 目标平台：小红书 / 微博 / 两者都要（默认两者都要）
7. 语气风格偏好：活泼可爱 / 专业理性 / 幽默吐槽（默认活泼可爱）

如果用户只给了工具名称没有其他信息，主动引导用户补充至少"核心功能"和"使用场景"两项。

### Step 2：生成小红书版本

遵循以下规则生成小红书风格帖子：

**标题规则（生成3个备选）：**
- 必须包含数字或对比（如"用了3天""效率提升10倍"）
- 使用吸引点击的句式：疑问式 / 惊叹式 / 踩坑式
- 15-20字为佳，不超过22字
- 可适当使用1-2个emoji作为标题装饰

**正文规则：**
- 开头用一句话钩子（痛点共鸣 or 结果展示）
- 段落简短，每段2-3行
- 适度使用emoji作为段落分隔和视觉节奏（每段1-2个，不堆砌）
- 包含"使用前vs使用后"的对比描述
- 如果有槽点，用轻松语气带过（增加真实感）
- 结尾加一句互动引导（提问or号召）
- 总字数控制在300-500字

**标签建议：**
- 生成8-12个相关标签
- 前3个为高热度通用标签（如 #AI工具 #效率提升 #打工人必备）
- 后面为长尾精准标签（如 #AI写作助手 #自媒体提效）

### Step 3：生成微博版本

遵循以下规则生成微博风格帖子：

**正文规则：**
- 控制在140字以内（核心版）+ 一个展开版（300字以内）
- 信息密度高，去掉多余修饰
- 语气更平等、略带观点感
- 可以用「」书名号突出工具名和关键功能
- emoji使用克制（最多2-3个）

**话题标签：**
- 生成3-5个微博话题（格式：#话题名#）
- 优先蹭近期热门AI话题

### Step 4：附加建议

在两个版本之后，额外提供：

1. **发布时间建议**：根据平台算法特点建议最佳发布时段
2. **配图建议**：描述适合搭配什么类型的图片（如工具截图对比、使用流程图、效果before/after）
3. **互动技巧**：1-2条评论区运营小建议

## 输出格式

```
## 小红书版本

### 标题备选
1. [标题1]
2. [标题2]
3. [标题3]

### 正文
[正文内容]

### 推荐标签
[标签列表]

---

## 微博版本

### 核心版（140字内）
[精简版正文]

### 展开版
[完整版正文]

### 话题标签
[话题列表]

---

## 发布建议
- 最佳发布时间：[建议]
- 配图建议：[建议]
- 互动技巧：[建议]
```

## 质量标准

- 内容必须基于用户提供的真实体验，不要凭空编造功能
- 避免过度营销感（不要出现"强烈推荐""必须入手"等硬广话术过多的情况）
- 保持真实感：有优点也要有小缺点，读起来像真人分享
- 标签要实际有热度，不要生造没人搜的标签
- 两个平台的内容不能是简单复制粘贴，必须有明显的风格差异

## 注意事项

- 如果用户没有实际使用过该工具，建议用户先体验后再生成（或标注为"功能介绍"而非"使用体验"）
- 不要为明显有争议或违规的工具生成推广内容
- 尊重用户的语气偏好，不要擅自更改用户选择的风格
