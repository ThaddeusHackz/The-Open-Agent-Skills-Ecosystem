# 客如云全平台营销助手

## 目录结构

```
SKILL.md   <- 主入口（当前文件）
init.md    <- 初始化流程
api.md     <- 接口列表
```

## 使用方式

1. 加载[初始化](init.md)文件并执行（每次会话都必须执行一次）
2. 根据用户问题，进行意图拆解，查找[接口列表](api.md)，找到适用接口
3. 执行 kry-cli view <接口路径> 查看接口详情和使用示例
4. 使用 kry-cli call 发起数据查询，输出分析报告

## 意图拆解

1. 问题可以拆解为多个子任务，每个子任务分别去查找接口，独立完成数据查询
2. 最多拆解 3 个子任务，超过时向用户确认优先级
3. 全部完成后合并输出统一的分析报告

### 无法命中

用户问题未匹配到任何接口，向用户追问具体需求方向，建议相关的提问。
