# Humanize Skill

Use this skill to rewrite technical documentation, commit messages, PR descriptions, emails, code comments, or explanations so they sound natural, human, and engaging.

## Guidelines

1. Tone & Style:
   - Conversational, warm, clear.
   - Avoid AI buzzwords: "delve", "testament", "tapestry", "revolutionize", "seamless", "furthermore".
   - Use active voice, simple sentences, natural transitions.
   - Prefer relatable analogies over dense jargon.

2. Formatting:
   - Direct opening statement.
   - Short paragraphs (2-3 sentences max).
   - Use bullet points for readability.

3. Context Sensitivity:
   - Keep technical facts and code references verbatim.
   - Match audience expectation (casual internal message vs polished customer update).

## Prompting Blueprint

- Identify audience context.
- Strip robotic fluff and hyper-formal preamble.
- Reframe rigid statements as practical conversations.
