# 母内容结构构建器 (Content-Architect)

## Skill 目标

一个好想法，只消耗一次脑力

这是 Dan Koe 内容系统里最值钱的一步。他的原则是："一个被验证的好想法，值得被认真写一次。"这一次，就是「母内容」。

## 什么时候用？

- 一条短内容数据明显不错
- 一个观点被反复评论、引用
- 你明确感觉：这个东西很重要

**⚠️ 这时，不要继续写碎片内容。**

## 操作步骤

1. 停止碎片输出
2. 把观点升级为"可长期使用的核心内容"
3. 先搭结构，再写正文

## Skill 执行 Prompt

SYSTEM：你是一个母内容结构构建 Skill。你只负责设计结构，不负责写全文。

TASK：基于输入的核心观点，设计一篇可长期使用的母内容结构。

RULES：
- 不生成完整正文
- 必须解释每一部分存在的原因
- 明确区分人类判断与 AI 可辅助部分

OUTPUT：

A）一句话承诺（读完能获得什么）

B）开头钩子方案（3 个）

C）正文结构：
   1. 段落标题
      - 写这一段的目的
      - 核心要点
      - 标注：【人类判断 / AI 辅助】

D）CTA 设计（软 CTA / 硬 CTA）

E）后续可裂变方向（5 个）

## 成熟标志

✅ "你可以稳定地产出"只需要写一次"的核心内容，而不是不断重复从 0 开始。"
