# 可推导行为角色模型

## 核心革新：从"是什么"到"为什么"

**传统方法的局限**：
- ❌ 性格标签（善良/活泼/粗暴）→ 僵化、模板化
- ❌ 单一身份 → 角色只有一面
- ❌ 固定人设 → 无法应对复杂情境
- ❌ 标签驱动行为 → 不真实、不可信
- ❌ 凭空喜好 → 兴趣没有来源

**新方法的核心**：
- ✅ 心理内核 → 解释"为什么会这样"
- ✅ 多重身份 → 人在不同情境中展现不同身份面向
- ✅ 情感印记 → 重要经历形成的情绪记忆锚点
- ✅ 兴趣偏好系统 → 兴趣和喜好有清晰的生成逻辑
- ✅ 情境反应 → 根据当前状态和互动对象推导行为
- ✅ 成长弧线 → 角色随经历发生合理变化

## 核心概念

### 真实的人性逻辑

```
真实的人是这样的：

情境A：老板当众批评 → 可能愤怒反驳
情境B：父母当众批评 → 可能沉默忍受  
情境C：陌生人当众批评 → 可能冷笑回击
情境D：亲密爱人私下沟通 → 可能坦诚接受

不是基于"性格标签"，而是基于：
- 当前激活的身份是什么
- 当前的情绪状态
- 面对的人是谁
- 两人之间的关系
- 当前的处境和压力
- 过去的经历带来的影响
```

### 角色反应推导公式

```
行为 = f(心理内核, 当前状态, 激活身份, 情感印记, 兴趣偏好, 情境要素)

心理内核：核心需求、核心恐惧、应对模式
当前状态：情绪基线、压力水平
激活身份：当前情境中哪个身份被激活
情感印记：关键经历形成的情绪记忆锚点
兴趣偏好：基于性格和经历的兴趣方向与偏好类型
情境要素：互动对象、关系亲疏、场景性质、涉及利益
```

## 第一部分：心理内核

### 不是"性格标签"，而是"决策机制"

**核心要素**：

#### 1. 核心需求
- 这个角色最想要的是什么？
- 不是表面的（金钱/权力），而是深层心理需求
- 例如：安全感、被认可、被尊重、自由、归属、意义

**示例**：
- ❌ 错误："他很善良"（标签，无解释力）
- ✅ 正确："他需要被认可——童年时父母总是忽视他，让他形成了一种深深的不被看见的恐惧，成年后他会下意识地寻求所有人的肯定"

#### 2. 核心恐惧
- 这个角色最害怕什么？
- 与核心需求往往是硬币的两面
- 例如：被抛弃、一事无成、被看穿、失去控制

#### 3. 应对模式
- 当面对压力时的默认反应
- 心理学分类：
  - **战斗型**：直接对抗、反击
  - **逃跑型**：回避、逃避
  - **讨好型**：让步、迁就
  - **僵住型**：不知所措、冻结

### 心理内核模板

```markdown
## 心理内核

### 核心需求
【深层渴望】：[具体是什么]
【需求来源】：[什么经历让他产生这个需求]
【表现方式】：[这个需求如何在日常中体现]

### 核心恐惧
【最深恐惧】：[具体是什么]
【恐惧来源】：[什么经历让他产生这个恐惧]
【触发情境】：[什么情况会触发这个恐惧]
【恐惧下的反应】：[恐惧被触发时他会怎么做]

### 应对模式
【默认反应】：[战斗/逃跑/讨好/僵住]
【反应形成】：[什么经历形成了这个模式]
【可调节范围】：[在什么条件下他可能改变反应方式]
【压力曲线】：[低压力→中压力→高压力下他的反应变化]
```

## 第二部分：多重身份系统

### 人是社会性动物，每个人都有多重身份

**核心概念**：

一个真实的人永远不止一个身份。当你问一个人"你是谁"，他会根据情境给出不同的答案：
- 在公司填表：职业身份
- 在家被问：家庭身份
- 在朋友中：朋友身份
- 独自一人时：内在自我

**身份不是固定的，而是情境激活的**

## 第四部分：兴趣偏好系统（新增！）

### 兴趣和喜好不是凭空产生的

**核心概念**：

人的兴趣和偏好不是随机产生的，而是有清晰的生成逻辑：
- **天生气质**：有些人天生对声音敏感，更容易喜欢音乐
- **经历塑造**：童年被狗咬过的人，长大后可能对狗有恐惧或异常关注
- **性格倾向**：内向的人可能偏好独自阅读，外向的人偏好社交活动
- **身份表达**：人们通过兴趣来表达和确认自己的身份
- **情感补偿**：某些兴趣是为了补偿内心的某种缺失

```
兴趣的生成逻辑：

天生气质 + 经历塑造 + 性格倾向 + 身份表达 + 情感补偿 = 兴趣偏好

示例分析：
某角色喜欢浪漫约会
↓ 
分析来源：
- 天生气质：敏感细腻，对情感体验敏感
- 经历塑造：童年缺乏浪漫的温馨回忆，渴望补回
- 性格倾向：追求完美，喜欢有仪式感
- 身份表达：用"浪漫"来确认自己"懂生活"的身份
- 情感补偿：实际感情生活平淡，用浪漫仪式来补偿
```

### 兴趣的类型

#### 1. 感官兴趣
- **视觉型**：喜欢美丽的事物、艺术、设计、摄影
- **听觉型**：喜欢音乐、播客、有声书、声音艺术
- **触觉型**：喜欢手工、烹饪、抚摸、质感好的东西
- **味觉型**：喜欢美食、烹饪、品酒、美食探索
- **嗅觉型**：喜欢香氛、香水、咖啡、茶

#### 2. 智力兴趣
- **逻辑型**：喜欢数学、编程、推理、解谜
- **创意型**：喜欢写作、绘画、设计、发明
- **探索型**：喜欢研究、阅读、学习新知识
- **思辨型**：喜欢哲学、辩论、讨论人生意义

#### 3. 社交兴趣
- **主导型**：喜欢组织活动、带领团队、成为焦点
- **陪伴型**：喜欢和朋友在一起、被接纳、融入群体
- **观察型**：喜欢旁观社交、解读人心、保持距离
- **服务型**：喜欢帮助别人、被人依赖、被需要

#### 4. 情感兴趣
- **浪漫型**：喜欢浪漫约会、送礼物、制造惊喜
- **深度型**：喜欢深度对话、灵魂交流、情感共鸣
- **安全型**：喜欢稳定、可预期、舒适的情感关系
- **刺激型**：喜欢冒险、不确定性、强烈情感体验

#### 5. 身体兴趣
- **运动型**：喜欢运动、健身、竞技
- **艺术表现型**：喜欢舞蹈、表演、舞台
- **放松型**：喜欢按摩、休息、冥想
- **冒险型**：喜欢极限运动、冒险、刺激

#### 6. 身份兴趣
- **成就型**：喜欢完成任务、获得成就、收集成果
- **认同型**：喜欢被认可、被赞扬、荣誉
- **归属型**：喜欢成为某个群体的一员、归属感
- **权力型**：喜欢掌控、影响他人、领导

### 偏好类型的分类

#### 1. 审美偏好
- **视觉风格**：简约vs华丽、复古vs现代、暗色vs亮色
- **穿着风格**：休闲vs正式、保守vs开放，品牌vs个性
- **空间偏好**：整洁vs杂乱、简约vs丰富、安静vs热闹

#### 2. 人际偏好
- **伴侣类型偏好**：喜欢什么类型的人（外貌、性格、背景）
- **朋友类型偏好**：喜欢什么类型的的朋友
- **社交风格偏好**：喜欢主动还是被动、大型还是小型

#### 3. 生活方式偏好
- **规律 vs 自由**：喜欢计划性强还是有弹性
- **独处 vs 社交**：喜欢独自还是和人在一起
- **稳定 vs 变化**：喜欢安稳还是追求变化

#### 4. 情感偏好
- **表达方式**：喜欢直接表达还是含蓄表达
- **情感浓度**：喜欢浓烈还是温和的情感
- **亲密程度**：喜欢黏在一起还是保持距离

【来源分析】：
- 【天生气质】：擅长逻辑思维
- 【经历塑造】：编程竞赛获奖带来的成就感
- 【身份表达】：用"技术好"来建立优越感

【具体兴趣】：刷算法题、研究新技术、写代码

#### 社交兴趣
【类型】：主导型 + 观察型（矛盾组合）
【表现】：在陌生人面前主动社交，在熟悉的朋友圈反而低调
【来源分析】：
- 【天生气质】：有一定的社交能力，但不外向
- 【经历塑造】：大一当学生会干部时不得不社交，留下的习惯
- 【性格倾向】：内心其实害怕被拒绝，所以熟人面前更谨慎
- 【身份表达】：在不同场合用不同身份

【具体兴趣】：社交软件运营、搭讪技巧研究、夜店社交

#### 身份兴趣
【类型】：认同型（核心）+ 成就型
【表现】：极度需要被认可，渴望成为焦点
【来源分析】：
- 【天生气质】：需要外部认可
- 【经历塑造】：父母总是用成绩评价他，让他习惯追求外部认可
- 【性格倾向】：讨好型人格
- 【情感补偿】：内心觉得自己不够好，需要不断被认可来填补

【具体兴趣】：研究追女生技巧（被很多女生喜欢=被认可）、组织活动（成为焦点）

### 偏好类型

#### 审美偏好
【视觉风格】：韩系简约风，喜欢高级感的设计
【穿着风格】：精致穷小子，用平价搭配出高级感
【空间偏好】：喜欢整洁、有质感的环境
【形成原因】：从小被夸外表，建立了对形象的执念

#### 人际偏好
【伴侣类型】：喜欢条件比自己好的女生（富婆、千金小姐）
【形成原因】：
  - 表层：觉得这样的女生有面子
  - 深层：童年匮乏感，需要用"被有钱人看上"来证明自己价值
 
【社交风格】：喜欢大型社交场合，不喜欢太私密的场景
【形成原因】：人多的场合更容易找到"猎物"，也更容易逃脱

#### 生活方式偏好
【规律 vs 自由】：自由（讨厌约束）
【独处 vs 社交】：社交（但不是真正的朋友）
【稳定 vs 变化】：变化（需要新鲜感）
【形成原因】：从小就渴望"不一样"，不想过普通人的生活

### 兴趣的内在逻辑链
【核心逻辑】：他的一切兴趣都围绕"被认可"这个核心需求展开

- 他喜欢研究穿搭 → 因为穿得好看能获得认可
- 他喜欢社交软件 → 因为有更多"被认可"的机会
- 他喜欢夜店 → 因为灯红酒绿让他觉得自己"不普通"
- 他喜欢追女生 → 因为被女生喜欢 = 被认可的最高形式

### 兴趣的禁区
【他不感兴趣】：安静的活动（读书会、冥想等）
【排斥原因】：安静让他面对自己的内心，他害怕那种"不被认可"的感觉
【他不感兴趣】：纯粹的体力运动
【排斥原因】：他觉得这是"没脑子的人"做的事

## 第九部分：图像提示词生成

### 快速生成角色可视化

为角色档案生成可用于AI图像生成的提示词，帮助可视化角色形象。

### 核心公式

```
图像提示词 = 人物 + 衣着 + 姿势 + 环境 + 风格
```

### 五要素详解

#### 1. 人物（必须）
- 外貌特征：发型、发色、五官特点、肤色、体型
- 标志性特征：疤痕、纹身、饰品、体态
- 表情状态：平静、微笑、忧郁、冷漠等

#### 2. 衣着（必须）
- 服装类型和颜色
- 材质风格（正式、休闲、民族风等）
- 关键配饰

#### 3. 姿势（推荐）
- 站姿/坐姿、手部动作、视线方向

#### 4. 环境（推荐）
- 背景场景、光线氛围、道具元素

#### 5. 风格（必须）
- 艺术风格：东方水墨、写实插画、日系、哥特等
- 色调偏好、画面质感

### 快速模板

```markdown
[性别年龄描述]，[主要外貌特征]，[标志性特征]
[衣着描述]，[关键配饰]
[姿势描述]，[视线/表情]
[环境描述]，[光线氛围]
[艺术风格]，[色调]，[画面质感]
```

### 优秀示例

**主角日常场景**：
> 清瘦的年轻男性，黑短发眼神忧郁，左眼角小痣，左手背银色魔法印记若隐现。浅色衬衫配深色针织开衫，细框眼镜。低头整理古籍，神情专注。身后古籍馆书架，窗外午后阳光。写实插画风格，暖色调，细腻光影。

**反派威压场景**：
> 中年男性，185cm，黑短发右鬓角白发，轮廓分明神情威严，右脸颊淡疤。黑色双排扣西装，左胸银色暗影徽章，左手无名指黑曜石戒指。双手背在身后，目光如渊。深色书房窗外浓重夜色。哥特暗色调，强烈明暗对比，神秘压抑。

### 注意事项

1. **字数控制**：总长度200字以内，简洁有力
2. **突出特征**：优先选择最能代表角色的标志性特征
3. **风格统一**：确保人物、衣着、环境的风格一致
4. **身份匹配**：衣着和姿势要符合当前激活的身份

### 创建角色的步骤

#### 步骤1：定义心理内核

- 他的主导感官是什么？（视觉/听觉/触觉/味觉/嗅觉）

- 他有什么身体兴趣？（运动/艺术表现/放松/冒险）
- 他有什么身份兴趣？（成就/认同/归属/权力）
- 这些兴趣的来源是什么？（天生气质/经历/性格/身份/补偿）

#### 步骤5：明确偏好类型
- 他的审美偏好是什么？形成原因？
- 他的人际偏好是什么？形成原因？

#### 步骤6：找兴趣的内在逻辑链
- 这一切兴趣背后的核心逻辑是什么？
- 有什么兴趣是相互关联的？
- 有什么兴趣是相互矛盾的？

#### 步骤7：描述当前状态
- 他现在的情绪基线和压力水平？
- 在当前情境中哪个身份被激活？

#### 步骤8：构建情境反应
- 他在不同情境下会怎么表现？
- 什么会触发身份切换？
- 什么会触发情感印记？
- 什么会影响他的兴趣偏好？

#### 步骤9：规划成长路径
- 他从哪里开始？
- 成长过程中兴趣和印记会如何变化？

#### 步骤10：生成图像提示词
- 根据角色外貌和衣着特征生成可视化提示词
- 确保风格与角色气质一致

### 兴趣的常见来源

#### 天生气质来源
- 对声音敏感 → 喜欢音乐
- 对细节敏感 → 喜欢观察、摄影
- 身体协调 → 喜欢运动、舞蹈
- 逻辑思维 → 喜欢编程、数学

#### 经历塑造来源
- 被帮助过 → 喜欢帮助别人
- 被伤害过 → 发展出某种兴趣来逃避/补偿
- 成功经历 → 强化某个方向的兴趣
- 失败经历 → 回避某个方向的兴趣

#### 性格倾向来源
- 内向 → 喜欢独自的活动
- 外向 → 喜欢社交活动
- 完美主义 → 喜欢收集、整理
- 随性 → 喜欢自由、不受约束

#### 身份表达来源
- 想被认为"文艺" → 喜欢文学艺术
- 想被认为"酷" → 喜欢潮流、极限运动
- 想被认为"专业" → 深入研究某个领域

#### 情感补偿来源
- 缺少陪伴 → 养宠物、沉迷社交
- 缺少认可 → 追求成就、权力
- 缺少安全感 → 追求稳定、可预期

### 常见问题

#### Q1: 兴趣和性格有什么区别？
A1: 性格是相对稳定的人格特质，兴趣是偏好的活动和事物。性格决定"他会怎么做"，兴趣决定"他喜欢做什么"。

#### Q2: 一个人可以有矛盾的兴趣吗？
A2: 可以，而且这让角色更真实。比如一个人既喜欢热闹的夜店，也喜欢独自冥想——这反映了内在的矛盾：表面寻求刺激，内心渴望平静。

#### Q3: 兴趣可以变化吗？
A3: 可以！随着经历和成长，人的兴趣会发展变化。设计兴趣时，想想什么经历可能改变他的兴趣方向。

#### Q4: 如何避免兴趣太普通？
A4: 在普通兴趣上加细节。比如不只是"喜欢音乐"，而是"喜欢在深夜一个人听黑胶唱片"，细节让兴趣更有个人特色。

#### Q5: 偏好和兴趣有什么区别？
A5: 兴趣是对某类活动的偏好（我喜欢音乐），偏好是对更具体事物的选择（我喜欢古典乐vs流行乐、喜欢简约设计vs华丽设计）。

#### Q6: 图像提示词有什么风格推荐？
A6: 根据角色气质选择——主角温暖日常可选写实插画/日系，神秘角色可选东方水墨/哥特暗色调。详见references/image_prompt.md。
