# CTO顾问 - 技术领导力工具

## 概述

本技能为技术领导者（CTO、技术总监、工程经理）提供全面的技术领导力指导工具，包括技术债务分析、团队规模计算、工程指标框架、技术评估工具和ADR（架构决策记录）模板。适用于评估技术债务、扩展工程团队、评估技术、制定架构决策、建立工程指标。

## 核心功能

### 1. 技术债务分析器
- 识别和量化技术债务
- 债务分类（设计债务、代码债务、测试债务等）
- 影响评估和优先级排序
- 偿还计划制定

### 2. 团队规模计算器
- 基于业务目标的团队规模规划
- 角色分配和技能矩阵
- 招聘计划和预算估算
- 团队扩展路线图

### 3. 工程指标框架
- DORA指标（部署频率、变更前置时间等）
- 团队健康指标
- 代码质量指标
- 生产环境指标

### 4. 技术评估工具
- 技术选型评估框架
- 成本效益分析
- 风险评估
- 实施路线图

### 5. ADR（架构决策记录）模板
- 标准化决策记录格式
- 决策背景和约束
- 备选方案评估
- 决策结果和影响

## 使用场景

### 技术债务管理
当需要评估和优先处理技术债务时，使用技术债务分析器进行系统分析。

### 团队规划
规划工程团队扩展时，使用团队规模计算器确定合理的人员配置。

### 技术决策
进行技术选型或架构决策时，使用技术评估工具和ADR模板。

### 绩效评估
建立和跟踪工程团队绩效时，使用工程指标框架。

### 团队规模计算公式
```
所需工程师数量 = (功能复杂度 × 开发速度) / (工程师生产力 × 时间约束)
```

### DORA指标计算
- **部署频率**：单位时间内的部署次数
- **变更前置时间**：从代码提交到生产部署的时间
- **平均恢复时间**：从故障发生到恢复的时间
- **变更失败率**：导致故障的变更比例

### ADR文档结构
1. **标题**：决策的简短描述
2. **状态**：提议/已接受/已弃用/已替代
3. **背景**：决策的背景和问题
4. **决策**：做出的决定
5. **后果**：决策的影响和后果
6. **备选方案**：考虑过的其他方案
7. **相关决策**：相关的其他决策

## 最佳实践

### 技术债务管理
- 定期进行技术债务评估（建议每季度）
- 将技术债务偿还纳入产品路线图
- 平衡新功能开发和技术债务偿还

### 团队建设
- 基于业务目标规划团队规模
- 建立清晰的职业发展路径
- 培养T型人才（深度+广度）

### 技术决策
- 基于数据和事实做决策
- 考虑长期影响而不仅是短期便利
- 记录决策过程和理由

### 指标跟踪
- 选择有意义的指标而非虚荣指标
- 定期审查和调整指标
- 使用指标指导改进而非惩罚

## 注意事项

1. **数据驱动**：基于数据和指标做决策
2. **平衡艺术**：平衡技术卓越和业务需求
3. **持续改进**：技术领导力是持续学习的过程
4. **团队赋能**：目标是赋能团队而非控制团队
5. **透明沟通**：保持决策过程的透明度

## 适用对象

- **CTO/技术副总裁**：制定技术战略和架构决策
- **技术总监**：管理多个工程团队和技术方向
- **工程经理**：管理单个工程团队和项目交付
- **技术负责人**：负责具体技术领域和架构设计
- **初创公司创始人**：建立技术团队和基础设施
