# OpenClaw 多代理作战编排

让复杂任务不再单线程：把一个大问题拆成可并行的子任务流水线。

## 适用场景

- 需要“调研 + 实施 + 复核”的复杂任务
- 需要跨文件/跨模块改动并保证质量
- 需要缩短总体交付时间

## 三段式编排模型

1. **Planner（策划）**：定义目标、约束、验收标准
2. **Builder（执行）**：按任务并行落地
3. **Reviewer（复核）**：一致性检查、风险评估、合并输出

## 关键规则

- 子任务必须写清：目标 / 输入 / 输出格式 / 完成标准
- 只并行独立任务，依赖链必须串行
- 任一子任务失败时，立刻补位（改派或主代理接管）

## 推荐执行步骤

### 1) 任务拆分

参考 `templates/task-brief.md`，把任务拆为 2-4 个可并行块。

### 2) 并行执行

使用子代理执行独立块（如文档调研、代码实现、测试验证）。

### 3) 结果合并

按 `templates/merge-checklist.md` 检查：

- 是否互相冲突
- 是否重复劳动
- 是否满足验收标准

### 4) 风险收敛

输出明确的：

- 已完成
- 未完成
- 风险与回滚路径

## 输出格式

- 结论
- 依据
- 风险
- 执行步骤

## 关键收益

- 显著降低复杂任务交付时间
- 结果更稳（执行与复核分离）
- 失败可控（有补位机制）
