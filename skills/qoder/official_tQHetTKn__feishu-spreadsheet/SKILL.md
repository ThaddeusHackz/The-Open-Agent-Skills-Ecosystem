## 与多维表格的区别

| 特性 | 飞书在线表格 | 飞书多维表格 |
|------|-------------|-------------|
| 定位 | 电子表格（Excel 替代） | 数据库 + 业务系统 |
| 数据结构 | 自由格式 | 固定字段类型 |
| 视图 | 单工作表 | 多视图（看板/甘特/日历） |
| 自动化 | 无内置自动化 | 支持自动化流程 |
| AI 功能 | 无 AI 字段 | AI 字段捷径 |
| 公式 | Excel 兼容 | 自定义函数 |
| 适用场景 | 数据分析、计算、图表 | 业务管理、流程、协作 |

**选择建议**：
- 做数据分析、财务模型、图表 → 用**在线表格**
- 做项目管理、CRM、业务系统 → 用**多维表格**

## 性能与限制

| 项目 | 限制 |
|------|------|
| 单个工作表最大行数 | 约 10 万行（建议 < 5 万保持流畅） |
| 最大列数 | 18278 列（理论上） |
| 公式数量 | 无硬限制，但 > 500 个可能变慢 |
| 图表数量 | 单工作表建议 < 20 |
| 数据透视表 | 数据源 <  ​10 万行为佳 |
| 文件大小 | < 100MB（飞书限制） |

**优化建议**：
- 数据量 > 5 万行时考虑分表
- 避免整列引用（A:A）
- 减少易失函数（NOW、TODAY、OFFSET）
- 定期归档历史数据
