# 闲鱼服务商品定稿（Xianyu Service Listing）

以 **财务岗** 为金标准样板（完整成品见 [references/example-finance.md](references/example-finance.md)）。任何岗位商品都按本 Skill 产出，保证结构、风格、合规一致。
**替换项只有 3 个：岗位名 + 场景词 + 标签**，其余全部锁死照搬。

> **内核 = 连接器·赋能**：交付物是"教会岗位本人用 AI + 把场景沉淀成他专属可复用的 skill"，**不是替他做完**。文案一律用"带你跑通/教会你/沉淀"口吻，**避免"帮你做/自动跑/交给你"的代做味**。价值链：① 一个真实场景让他眼见为实 → ② 教会他 → ③ 沉淀成他的专属 skill。

## 何时使用
- 新建某岗位的闲鱼商品文件夹；
- 把已有商品（电商/外贸/运营/行政HR/律师/业务变产品）对齐到金标准；
- 编写或校验 `发布内容.md`。

## 目录与文件（固定）
一个商品 = 一个文件夹，放在 `闲鱼上架/` 下，命名 `商品N_<岗位>`：
```
商品N_岗位/
├── 发布内容.md          # 闲鱼全字段，见下方模板
├── 01_首图.png          # 该岗位交付样例图（含数字钩子带）
├── 02_卖点封面.png      # 通用卖点封面（各商品相同）
└── 03_个人资质卡.png    # 信任图（各商品相同）
```
- 图片**固定 3 张**；出真实好评后，用好评/交付截图**替换**其中一张，仍保持 3 张。
- 上传顺序即文件名前缀 `01 → 02 → 03`。

## 导出 PNG（Inkscape，2倍）
```bash
# 用 Inkscape 命令行把首图 SVG 导出为 2 倍 PNG（inkscape 路径按本机安装位置调整）
inkscape <首图.svg> --export-type=png --export-filename=<商品文件夹>/01_首图.png --export-dpi=192
```
- 192 dpi ≈ 2 倍清晰度；导出后**核对文件大小 > 0**（中文输出路径偶发写空文件）。
- 无 Inkscape 时可用 Chrome/Edge headless 截图、resvg、rsvg-convert 等等价方案。
