# OpenClaw 记忆治理引擎

把“记住更多”升级为“记住对的、忘掉错的”。

## 解决痛点

- 记忆越多越乱，召回命中率下降
- 短期事件挤占长期事实
- 过时信息长期残留导致误导

## 治理闭环

1. **采集**：daily note 记录原始事件
2. **评分**：按复用价值/时效性/可信度打分
3. **提炼**：高分信息沉淀到 `MEMORY.md`
4. **淘汰**：过时或冲突信息标注或删除

## 实施步骤

### 1) 建立评分标准

使用 `templates/memory-quality-rubric.md`，为每条记忆打分：

- 复用价值（0-3）
- 时效性（0-3）
- 可信度（0-3）

### 2) 每日记录，周度提炼

- 每日：写 `memory/YYYY-MM-DD.md`
- 每周：提炼“长期稳定事实”到 `MEMORY.md`

### 3) 检索前置规则

涉及历史决策/偏好/日期时，先执行：

- `memory_search`
- `memory_get`

再给结论，避免“拍脑袋回忆”。

### 4) 冲突消解

当出现新旧冲突：

- 标注旧条目为“过时/待验证”
- 写入新条目并附验证依据

### 5) 月度清理

- 删除低价值噪声条目
- 合并重复结论
- 保持 `MEMORY.md` 结构稳定可读

## 产出模板

- 结论
- 依据（命中来源）
- 风险（不确定项）
- 执行步骤

## 关键收益

- 历史召回更准
- 错误记忆更少
- 长期协作稳定性明显提升
