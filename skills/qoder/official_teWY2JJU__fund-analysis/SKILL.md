# Fund Analysis Skill

查询基金信息、分析业绩、评估风险。支持单基查询、批量查询、基金对比。

## 功能

- **查询**：获取基金基本信息（名称、净值、涨幅）
- **批量查询**：一次性查询多个基金（最多10个）
- **对比**：两个基金的业绩、持仓结构对比
- 数据来源：天天基金网（实时抓取）

## 用法

### 命令行

```bash
# 单基查询
fund-analysis query <基金代码>

# 批量查询
fund-analysis batch <代码1> [<代码2> ...]

# 基金对比
fund-analysis compare <代码1> <代码2>
```

示例：
```bash
fund-analysis query 006719
fund-analysis batch 006719 000001 110022
fund-analysis compare 006719 000001
```

### 在 OpenClaw 中调用

直接说：
```
帮我查一下基金 006719 的信息
```
或
```
对比一下 006719 和 000001 哪个更好
```

Agent 会自动选择合适命令。

## 数据来源

- 天天基金网 (https://fund.eastmoney.com)
- 数据通过网页抓取实时获取

## 限制

- 依赖目标网站结构，如页面改版需更新解析逻辑
- 无法获取实时交易、申赎状态等动态数据
- 批量查询建议不超过10个，避免被限制访问
- 仅供信息参考，不构成投资建议

## 风险提示

基金投资有风险，过往业绩不预示未来表现。请仔细阅读基金合同、招募说明书等法律文件，根据自身风险承受能力谨慎决策。
