# 小红书图文生成 Skill

## 触发条件

用户提供**源内容**（文章链接、文本、观点、知识段落等）并要求以下任一任务时启用：

- 将内容转换为小红书图文笔记
- 生成小红书风格的配图/封面/内容图
- 将复杂内容分解为多张图片展示
- 生成 1～10 张的小红书图文系列

## 执行流程

### 1. 内容分析

对用户提供的源内容进行深度分析，识别以下维度：

| 维度 | 说明 | 输出 |
|------|------|------|
| **内容类型** | 教程类 / 观点类 / 知识科普类 / 产品种草类 / 经验分享类 / 故事类 | 类型标签 |
| **核心钩子** | 前 3 秒吸引注意力的标题/开头 | 3～5 个备选钩子 |
| **目标受众** | 谁会对内容感兴趣 | 受众画像描述 |
| **互动潜力** | 评论/收藏/分享驱动力 | 互动点清单 |
| **情感基调** | 专业/温暖/幽默/严肃/治愈/燃 | 基调标签 |
| **信息密度** | 高/中/低 | 决定图片张数 |

### 2. 确定图文数量

根据内容分析结果确定图片张数（1～10 张）：

| 信息密度 | 建议张数 | 适用场景 |
|---------|---------|---------|
| 低 | 1～3 张 | 简单观点、金句、碎片知识 |
| 中 | 4～6 张 | 教程、经验分享、产品种草 |
| 高 | 7～10 张 | 深度文章、完整知识体系、详细教程 |

**封面**（第 1 张）和**结尾**（最后 1 张）固定为特殊角色，中间为内容图。

### 3. 风格适配

根据内容分析结果，从以下维度组合视觉风格：

- 从 `references/style/` 目录中选择匹配的风格定义（如 `blue-print.md`）
- 从 `references/layout/` 目录中选择页面布局模板
- 若引用不存在，使用通用风格规则（见 `prompt/system.md`）

#### 风格选择矩阵

| 内容类型 | 推荐风格 | 理由 |
|---------|---------|------|
| 教程/干货 | 技术蓝图 / 极简 | 信息结构清晰，逻辑性强 |
| 观点/态度 | 手绘插画 / 涂鸦 | 个性鲜明，有温度 |
| 知识科普 | 信息图表 / 蓝图 | 层次分明，便于理解 |
| 产品种草 | 清新 / 高质感 | 视觉吸引力强 |
| 经验分享 | 温暖手绘 / 生活感 | 亲切自然 |
| 故事类 | 叙事插画 / 漫画 | 有代入感 |

### 4. 生成图文提示词

对每张图片分别生成完整的文生图提示词，包含：

- **角色定位**：封面 / 内容图(第N张) / 结尾
- **画面描述**：详细说明构图、元素、色彩
- **文本内容**：精准的图文文案（提炼核心+口语化表达）
- **风格要求**：基于第 3 步的风格选择
- **尺寸规格**：小红书竖版 3:4 或 9:16

### 5. 组装输出

输出格式为 Markdown，每张图片一个独立的提示词块，示例如下：

```markdown
# [标题]

## 图片总览
- 总张数：N
- 风格：[风格名称]
- 内容类型：[类型标签]

---

## 第 1 张 · 封面

### 文案
[封面标题 + 引导语]

### 画面描述
[详细构图说明]

### 提示词
\`\`\`
[完整的文生图提示词]
\`\`\`

---

## 第 2 张 · 内容图

...
```

## 内容拆解规则

### 封面（第 1 张）
- 使用强钩子标题，引起好奇心
- 视觉冲击力强，色彩鲜明
- 突出核心卖点/观点
- 不超过 15 个字的主标题

### 内容图（中间 N-2 张）
- 每张图只传递 **1 个核心信息**
- 图文互补：图上放金句/关键词，细节在文
- 信息层层递进，有逻辑顺序
- 每张图之间留"翻页钩子"（点击感）

### 结尾（最后 1 张）
- 引导互动：提问/投票/观点
- 引导收藏：总结/清单/行动号召
- 引导关注：价值暗示（"持续更新干货"）
- 包含 CTA（Call to Action）标签

## 文案规范

| 要素 | 要求 |
|------|------|
| **标题** | 强钩子，制造好奇心或共鸣，≤ 20 字 |
| **正文风格** | 口语化，短句，分段清晰，善用emoji |
| **关键信息** | 提取最 impactful 的 3～5 个点 |
| **互动引导** | 结尾图 + 评论区引导 |
| **标签** | 3～5 个相关话题标签 |
