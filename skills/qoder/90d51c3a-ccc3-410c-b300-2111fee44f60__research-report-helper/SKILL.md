# research-report-helper — 企业级研究报告

## 这是干什么的

把研究问题按**小型咨询项目**跑完，产出**自包含 HTML**（双击即开、Ctrl+P 出 PDF、截屏即用）。**默认最高标准**：T1+T2 信源 ≥ 50 条、8-10 章、AntV 蓝配色、不下"buy/sell/建议"结论词。

**不触发**："XX 现在多少钱"这类行情点查。

## 工作流（六阶段，按需读子文件）

```
1. 研究   → guides/02_research.md     [契约 / 假设 / 信源 / 代表性 / 交叉验证]
2. 撰写   → guides/03_writing.md      [首句亮结论 / MECE / 四段式 / 纪律]
3. 视觉   → guides/04_visual.md       [语言规范 / 选型决策树 / 字体 / 工程规范]
4. 自检   → guides/05_review.md       [内容节奏 / 视觉 / 图表 / 表格 / 数据可信 / 输出形态]
5. 渲染   → guides/06_pipeline.md     [HTML 直接生成 / 信息图 SSR / 数据图 / 踩坑清单 / 通用化方法论]
6. 核查   → guides/07_factcheck.md    [核查清单 / 方法 / 反例 / 失败处理]
```

**附录**（按需查）：`guides/01_workflow.md`（总览）/ `guides/A_engineering.md`（CDN + SSR）/ `guides/B_cheatsheet.md`（速查表）。

## 五条最高纪律（任何时候都先想这五条）

1. **数据可信度优先于信源权威**——不推测、不补全、不以偏概全，**宁可不写，不可推测**
2. **先论点后图表**——数据图按 §5.2.1 决策树；信息图按 §5.2.2 七大结构 + §5.2.2.1 L.A.T.C.H
3. **HTML 直接生成**——**不走 md→html 正则转换**，用 Python/Node 脚本直接拼装
4. **精度反映可信度**——L1 精确 / L3-L4 约数；读者要能分清"事实"和"估算"
5. **目标感来自克制**——少装饰、多信息、独立判断；不居高临下
