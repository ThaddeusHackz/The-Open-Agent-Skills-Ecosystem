# 语法检查工具（AMA）

该工具专为医学写作提供专业的语法检查服务，遵循AMA（Ask Me Anything）的编写规范。

## 使用方法

```bash
python scripts/main.py --text "Your text here"
```

## 参数

| 参数 | 类型 | 默认值 | 是否必填 | 描述 |
|---------|-------|---------|---------|-------------------|
| `--text`, `-t` | 字符串 | - | 是 | 需要检查的语文内容 |

## 功能特点

- 能够检测被动语态
- 确保文本符合AMA的写作风格
- 验证医学术语的正确性

## 输出结果

提供语法修改建议及相应的解释。
