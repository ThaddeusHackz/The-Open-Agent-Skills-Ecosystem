# 阴阳岛肉鸽

## 简介
像素风格修仙肉鸽游戏，玩家在阴阳岛轮回历劫。

## 玩法
- 职业选择：医师 / 炼药师 / 武痴
- 武器进化：徒手 → 银针 → 葫芦 → 拂尘 → 太极剑 → 炼丹炉
- 境界系统：筑基期 → 金丹期 → 元婴期 → 化神期 → 渡劫期
- 诅咒系统：血光 / 灵气流失 / 道心不稳（可用祭坛消除）

## 触发词
- 打开游戏
- 开始阴阳岛
- 玩肉鸽

## 使用
直接打开 `index.html` 即可游玩。
