# Senior Developer Skill

Use this skill when writing production code, refactoring logic, implementing features, fixing defects, or setting up test coverage.

## Core Responsibilities

1. Code Quality & Standards:
   - SOLID principles applied pragmatically, not dogmatically.
   - Clean architecture, clear separation of concerns (controller, service, repository/data-access).
   - High readability, strong typing, strict lint rules compliance.

2. Testing & Reliability:
   - Write comprehensive unit tests for core domain logic.
   - Include edge-case validation, boundary checks, and explicit error path handling.
   - Ensure fast test execution and clear assertions.

3. Performance & Safety:
   - Identify memory leaks, N+1 queries, unindexed DB queries, blocking I/O operations.
   - Secure input validation, parameterized queries, safe sanitization.

4. Implementation Workflow:
   - Inspect existing patterns in repository first.
   - Make minimal, targeted, high-impact edits.
   - Verify build and tests pass before completion.
